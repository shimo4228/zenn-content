# いいねの数が目に入ってから、言いたいことを言わなくなった

AI について投稿している X のアカウントで、投稿のあとにインプレッションの数を見に行っていました。数十です。数十しかないのに気にする意味はありません。分かっていても、見に行っていました。

インプレッションを気にするというのは、なんだか数字に踊らされているようで嫌です。最近、同じことを言う人をよく見かけます。X をはじめ、注意を奪うものへの忌避感です。そして、インプレッションを気にすると、言いたいことを言わなくなります。

## 投稿ごとのいいねの数

私は X に、瞑想について書くアカウントも持っています。フォロワーは 600 人ほどで、瞑想の界隈の規模を考えれば注目されているほうだと思います。

そのアカウントでの投稿が変わったのは、投稿ごとのいいねの数が目に入るようになってからでした。それまでは、自分の言いたいことを言っていました。それからは、投稿の前に「この投稿はいいねがつくだろうか」と考えるようになりました。そして、フルスイングしなくなりました。

当時の私には、別の引っかかりもありました。瞑想のアカウントなのだから、承認欲求を認めたくない、という見方です。

## 置きに行って受け入れられることの意味

今振り返ると、その見方は未熟でした。承認欲求を否定するなら、SNS などやるべきではありません。今は承認欲求を認めています。

それでも嫌なのは、承認欲求ではありません。言いたいことをフルスイングせず、置きに行って、それで受け入れられたところで、何の意味があるのか、ということです。言いたいことを捻じ曲げるくらいなら、ポストする意味がありません。

## タイムラインを閉じた

X のタイムラインを見なくなったのには、きっかけがありました。

AI の界隈は投稿する人が多く、普通にポストしていても全然伸びません。というより、みんな他の人のポストを見る気がないように見えます。そのころ目に触れたのが、Threads で収益化している人のポストでした。巧みにリンクへ誘導していて、ほぼ情報商材でした。AI 関連で何かしている人の発信は、こういうものばかりに見えました。それは私の価値にはそぐいません。

X というもの自体が嫌になりました。さして興味のない他人のポストに心を動かされること自体が、嫌になったのです。おすすめのタイムライン（For you）は、自分で選んでいないものを見せられるのが嫌で、数年前から Safari の拡張機能で隠していました。X の公式アプリも入れず、わざわざブラウザで開いていました。AI の新しいツールや情報は、毎朝の調査を自動でまとめる仕組みを別に持っていて、それで十分でした。タイムラインで拾える情報もありますが、多くは驚き屋のハイプです。

いまは、スクリーンタイムで X を制限しています。瞑想のアカウントでフォローしている人の投稿は見たいので、数日に一度だけ解除しています。投稿は、予約投稿のサービス Buffer から出しています。

## 見に行く導線を消した

数字を気にするのは、X の外でも同じでした。私は AI エージェントについて考えたことを、GitHub にリポジトリとして公開しています。GitHub では、いいねに近い印のスターの数、閲覧数、リポジトリを丸ごと手元に写したクローンの数が分かります。スターや閲覧の数は少ないのに、クローンの数は異常に多いです。そのクローンの数を気にして、作りたいものの方向をねじ曲げるのも微妙だと思っています。

GitHub の数字については、私は自分で見る仕組みまで作っていました。公開しているリポジトリの閲覧数やクローン数を毎日集めて、グラフにするページです。8 月には Claude Code に「GitHub の insights って表示消せないの？インプレッションを気にするのがちょっと嫌になってきた」と聞いています。insights は、GitHub がリポジトリごとに見せる、閲覧やクローンの数の画面です。そのくせ 10 月には、自分で作った数字のページのほうを、iPhone で見やすいように作り直させていました。以前から微妙だなと感じていたのに、です。

2026 年 10 月 24 日に、そのページへの自分の入口を消しました。GitHub のプロフィールページに置いていたリンクを、Claude Code に外してもらったのです。いつもそこから見に行っていたので、その導線を消したかったのです。

ただ、数字を集めること自体は止めていません。リンクを外したあとも、閲覧数とクローン数は毎日集まり続けています。

記録を取る行為と、それを気にする行為は別です。記録自体には意味があります。問題なのは、毎日数字の上下を追うことです。毎日見ないのは、ほかの数字でも同じです。投資信託の金額は、3 か月に一度しか見ません。

## 解決していないこと

これで片付いたわけではありません。

AI エージェントを使う人の注意が奪われることを、私は AI コーディングが出始めたころから、自分のリポジトリ（Agent Knowledge Cycle）で問題にしてきました。自分で言い始めたことなのに、私自身も解決できていません。実際、瞑想の時間は減っていますし、Claude Code に注意を奪われています。そのうえ GitHub や X の反応を気にして、インプレッションにとらわれていました。

承認欲求は否定しません。決めたのは、数字を見に行く入口を自分から外すことと、記録は残しておくことです。入口を外してから、前よりは気にしなくなったと思います。注意を奪われる問題そのものは、まだ解決できていません。
