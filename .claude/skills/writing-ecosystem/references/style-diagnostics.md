# Style diagnostics

執筆の背骨（`.claude/rules/writing-principles.md`）だけでは具体的な slop / voice drift を特定できないとき、または日本語稿を公開前に推敲するときに読む診断表。
文字列 blacklist ではない。原稿固有の意味を持つ用例は残し、汎用評価・定型リズム・機械的な弱化だけを直す。
語の規則は背骨 2 が持つので、この表に症状語の行は足さない。

## Generic language

| Pattern | Replace with |
|---|---|
| 画期的 / 革命的 / 革新的 / game-changer / revolutionary | 従来との差分、観察、数値 |
| 素晴らしい / 驚くべき / powerful / robust | 何がどう良い、強い、予想外だったか |
| シームレス / seamlessly / effortlessly | 実際の操作と必要な手間 |
| 深い洞察 / 重要な示唆 / 本質的な問い | 洞察・示唆・問いそのもの |
| 最先端 / cutting-edge / ever-evolving | 何が新しく、いつの情報か |
| leverage / 活用する | 具体的な動作、または plain `use` |
| 手元 / 手元で / 手元の環境 | 指している場所を具体的に書く（ローカル PC、自分の Mac、社内サーバー） |
| 造語・証拠台帳や内部の呼び名（梯子、arm、face、shadow 等） | 既存の名前で呼ぶ（梯子 → アブレーション。規則は背骨 2）。既存の名前が無いときはやったことの名前で書く |
| Moreover / Furthermore / It's worth noting | 接続を直接書くか削る |
| delve / multifaceted / holistic / transformative / pivotal / landscape / tapestry / unlock / harness / unleash / empower / paradigm | 原稿固有の名詞と動詞 |

## Structural tells

| Pattern | Diagnostic action |
|---|---|
| `It's not X, it's Y` / 「XではなくYだ」の反復 | 対比の型を外して主張を直接書く |
| 予告付きの3点列挙、同形のbold段落が3連以上 | 実在する分類だけ残し、段落の長さと形を変える |
| em dash、colon、semicolonによる等間隔リズム | 記号を置換せず、文を再構成する |
| 因果を箇条書きにしている | 文でつなぐ。並列は箇条書き、比較は表のまま残す |
| `Great question` / 「素晴らしい質問」 | 本題から始める |
| `Hope this helps` / 「参考になれば」「いかがでしたか」 | 最後の実質的な文で終える |

## 文の手当て

- 副詞を削り、動詞を強くする。数値で言えるなら数値で言う
- 能動態を既定にする。行為者を伏せるのは理由があるときだけ
- 「〜において」のような硬い言い回しは、平易な言い回しに直す
- 第 2 稿は第 1 稿より短い。論点を前へ進めない文を削る

## 日本語の構文の手当て

日本語稿の構文を推敲で直すときに読む。語の規則は背骨 2、確度は背骨 1 が持ち、ここは直す前後の照合と直し方の型だけを置く。
例は一つの稿から取った。下で「著者の」と呼ぶ文は、本文の「」の引用、`drafts/<slug>.corrections.md`、commit 本文の `指摘:` ブロックで見分ける（背骨 2 が著者の語のまま残すと定める文）。

### 照合（案を採る前に）

案を書いたら原文と次の 8 点を並べ、1 点でも変わった案は捨てて原文を残す:
主題、認否、動作主と相手、範囲と条件、確度、時制と相、数値と固有名と時期、著者の文の動詞。
物を主語にした文を書き手の主語に直す型では、主語は変わってよく、動作主が同じであることを照合する。
足した語（「続けて」「とも」）も照合に入れる。

- 手を入れるのは地の文。「」の中は一字も変えず、引用は丸ごと残す。引用と地の文が重なったら地の文の側を削る。
  引用を削るのは著者が許したときで、そのときも時期と理由を担う部分は残す
- 削っても残すもの: 結論の前の条件句（「並べて読むと」）、対比の「は」（「取り込みは続けています」）、
  「〜わけではない」の否定、時期（「この半年ほどで」）、範囲の語（「英語の枯渇の証言も」）
- 著者の文は著者の語のまま残す（背骨 2）。名詞のラベル（「私がいつも言っていること」→「私の口癖」）や類義の動詞
  （感じていた → 抱いていた）へ置き換えた案は捨てる
- 一拍置いた形は残す: 著者が書いた常体と決め台詞、段落の山場と余韻の短文、著者の一行段落（「見つかるのは、剥奪のほうです。」）、題を繰り返す独立した一句、
  結論を二文で落とす段差。二文を「XではなくY」の一文にまとめると Structural tells の反復になる。
  推敲者が作った断片（「12 回。」）には述語を戻す
- 直したら全文で、接続詞（ところが・けれど）・段落の書き出し・文末を数え直す。消した反復が別の反復になっていたら元の形に戻す

### 型

| Pattern | Diagnostic action |
|---|---|
| 同じ文末の短文が 3 つ以上続く（「〜です。〜型です。〜です。〜型です。」） | 中身のつながる文を「で」「て」でつないで連続を切る（「ひとつは剥奪で、…奪われる型です。もうひとつは枯渇で、…型です」）。語尾は周りの register にそろえる |
| 引用の枠が毎回同じ形（「〜にこう書いています。「…」」） | 時制・動作主・枠の動詞はそのまま、受け方を変える。著者が引用を削ってよいと言った稿では、引用を地の文に畳む（「…のも大きい、とも書いています」）。話し手と場所は引用の前に置き、引用を受ける述語を残す |
| 枠の動詞を名詞にした形（「〜への説明はこうです」「〜のは、「…」ということです」） | 動詞に戻す（「〜にこう説明していました」）。名詞の形は、誰が何をしたかを文から消す |
| 引用節を名詞で抱え込む（「〜、という決まりがあります」） | 名詞を先に出し（「決まりが一つあります」）、中身を次の文に置く。あとの文が指す名詞（決まり）は受け皿として残す。同じ語が重なる形（「型を決める決まり」）になったら語順を戻す |
| 長い修飾つきの名詞が文頭に来て、誰の話か文末まで分からない | 主題を文頭へ出し、長い修飾を述語の近くへ移す |
| 一文に読点が 3 つ以上あり、時の句が主語と述語の間に挟まる | 時の句を文頭へ移す（「去年の暮れごろから、いまのエンジニアにも同じことが起きているように、私には見えます」）。外すと同じ音が詰まる読点（「だからこそ、その」）は残す |
| 読点を足して区切る | 足す前に、かかり先が変わらないか確かめる（「毎週の上限近く」→「毎週、上限近く」は意味が頻度に変わる） |
| 物が人の動作をする（「9 月の記事は…と書いていました」） | 書き手を主語にし、媒体は「〜の記事で」と場所に下ろす（「能動態を既定にする」の実例）。著者自身が物を主語にした言い回しは残す |
| 一文の中か隣の文で同じ動詞・長い語句が重なる（「やれることを…やれました」） | 片方を削って述語を一つにする。残す語は同じ語のまま（用語の手当て）。定義した用語と、前で決めた手順の名（「並べて読むと」）は論の要なので繰り返しを残す |
| 予告だけの文（「ここで使うのは二つです」）、場所や時を 2 文に分けた導入 | 続く中身の文と 1 文にする（「英語の掲示板 Hacker News でも同じことが起きました」）。吸収するとき、範囲の語（だけ、までに）と具体名を新しい文へ持ち込む |
| 修飾を重ねた指示（「リポジトリを始めたころのその会話」）、指す先が二つに読める指示語 | 同じ節の中なら「先の会話」と短く受ける。指示語は直前に候補が一つのときに使い、節をまたぐなら名前で呼ぶ |
| 毎文に「私は」がある | 段落の頭で一度示したら、あとは落とす。対比の「私には」「私にも」は残す |

## 用語の手当て

名前の扱いの規則は背骨 2 が持つ。ここは直し方の実例だけ。組み合わせてよい。

- 見出しから外し、本文に落とす
- 具体的な現象を先に見せ、名前は後からつける
- 一度定義したら同じ語を使い続ける（類義語に逃げない）
- 確立した概念に由来するなら初出で系譜を示す
- 英語直訳語を疑う（floor →「床」、name / pinpoint →「名指しする」）。意味の通る技術語か、日本語で普通に言う動詞（分かる、言える、指摘できる）に置き換える
- 英語の名詞句を 2 つ以上そのまま繋げない（「read-only な second opinion を一発で」）。
  固有名詞・製品名・コード内ラベル・一貫使用の定着語は例外

## 発見調の register

channel contract が発見調を宣言する場合だけ使う。

| 使う（発見調） | 避ける（根拠以上の宣言） |
|---|---|
| 「〜だった」「〜と気づいた」 | 「〜すべきだ」 |
| 「〜と感じた」「〜に見えた」 | 「〜に違いない」 |
| 「気づいたらそうなっていた」 | 「〜を示している」 |
| 「少なくとも方向としては悪くない」 | 「設計は正しかった」 |

## Assertion strength

規則は背骨 1。ここは言い回しの実例だけ。

- 因果が推論なら「〜と読める」、評価を読者へ返すなら「〜ではないか」を使える。
- 同じ結論を疑問形で繰り返さない。問いは入口・転換・結論の必要な一箇所に置く。
- hedging を一律に足さない。未検証範囲と確信度を具体的に書く。
