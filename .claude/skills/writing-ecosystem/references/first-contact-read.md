# 初見の読み — Codex に渡す文面

`writing-ecosystem` §4 が `codex:codex-rescue` に渡す文面の正本。毎回組み立てず、`<...>` だけを埋めてそのまま渡す。
稿を先に読ませ、checklist は後に読ませる（checklist を先に読むと、checklist の答えを探しながら読む）。

```text
Read-only review. Do not edit files (no --write).

まず原稿 <原稿の path> を、<channel contract の path> の <channel> 行の読者として、前から 1 回だけ読む。
読み終えてから <repo>/.claude/agents/prose-clarity-reviewer.md の checklist を読み、その形式で報告する。
加えて、本文から弁護できるカテゴリのすり替え・事実の矛盾・帰属の誤りを挙げる。ヘッジの追加は求めない。日本語で書く。
```

渡すのは原稿・contract・checklist の path だけ。brief、central thesis、causal spine、成功基準、ほかの reviewer の結果は渡さない。
