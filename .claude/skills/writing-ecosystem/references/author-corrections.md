# 著者の指摘の記録 — 雛形

規則は SKILL.md「指摘の処分規律」の「著者の指摘を積む」「著者の撤回」「commit へ写す」が持つ。ここに置くのは 2 つの雛形だけ。

## 積む 1 件（`drafts/<slug>.corrections.md`、非公開）

```markdown
## C<n>
- 原文: 「<著者の発言をそのままコピーする>」
- 対象: <brief / 節名 / 文>
- 修正前: <抜粋 2 行まで>
- 修正後: <抜粋 2 行まで>
- Trigger: <何が起きて著者が指摘したか（例: 通読で結論が 2 つに読めた）>
- Expect: <この修正が外れていたと分かる観測（例: 公開後の反応で同じ箇所が誤読される）>
- commit: <写した commit の SHA。写したあとで書き足す。複数件をまとめて写したら、ファイル末尾に「C1〜C<n> は commit <SHA> に写した」と 1 行で書いてもよい>
```

著者が反映を却下・撤回した件は、その件に `- 撤回: <撤回した著者の発言と、どこまで戻したか>` を足して残す。

## 写す 1 ブロック（commit 本文）

`Context:` / `Decision:` / `Review-when:` の後ろに、1 件 1 ブロックで空行を挟んで並べる。

```text
指摘: 「<原文>」
Trigger: <…>
Expect: <…>
```

`[略]` に置き換えた原文は、同じ行の括弧に何を伏せたかを書く（例: `（[略] は第三者の人名）`）。
