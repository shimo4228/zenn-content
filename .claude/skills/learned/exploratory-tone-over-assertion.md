# Exploratory Tone Over Assertion

**Extracted:** 2026-03-20
**Context:** 技術記事で自分の設計・実装について書くとき

## Problem
AI は「設計は正しかった」「これが最適だ」と断定的に書く傾向がある。
著者がまだ確信していない段階でこれをやると、記事の誠実さが損なわれる。

## Solution
以下の変換を校正時に適用する:

| AI が書きがち | 著者の実感に近い表現 |
|-------------|-------------------|
| 「設計は正しかった」 | 「少なくとも方向としては悪くない」 |
| 「意図しない汎用性の創発だ」 | 「結果的に汎用性が生まれていた。狙ったわけではない」 |
| 「理にかなっている」 | 「うまくいくかどうかはまだわからない」 |
| 「〜を示している」 | 「〜と感じた」「〜に見えた」 |
| 読者への指示（「読み比べてみてほしい」） | 削除、または事実の提示のみ |

## When to Use
- 著者が「まだわからない」「自信がない」と言ったとき
- 記事が自分の設計・実装についての報告のとき
- editor が「断定トーン」を指摘したとき
