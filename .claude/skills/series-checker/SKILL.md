# Series Checker Skill

**Purpose:** シリーズ記事の整合性を確認し、用語ドリフト・前提知識の断絶・トーンの不一致を検出する。

---

## Usage

```
/series-checker articles/new-article.md --series "article1.md,article2.md"
```

---

## Check Items

### 1. 用語一貫性

新しい記事で使われている用語が、シリーズの過去の記事と一致しているか:

- 同じ概念に異なる名前を使っていないか
- 過去の記事で定義した用語を再定義していないか
- 用語の意味が微妙にドリフトしていないか

### 2. 前提知識の連続性

- 前の記事で説明した概念を、この記事では説明なしで使えるか
- 前の記事を読んでいない読者に、最低限のリンクや要約があるか
- 前の記事の結論を、この記事の前提として正しく使っているか

### 3. トーンの一貫性

- シリーズ全体のトーン（だ/である調 or ですます調）が統一されているか
- Voice Pattern（毒の効いたユーモア等）がシリーズ内で一貫しているか

### 4. 内容の重複

- 前の記事と同じ内容を繰り返していないか
- 「前回の記事で述べた通り」の後に、前回の内容をそのまま繰り返していないか
