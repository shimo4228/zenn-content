Central thesis: 人間と LLM のどちらが読むかは、定義しきれない。読み方はハイブリッドになっていくはずだから、
分けて考えるのではなく、どうすれば両立するかを考えることが重要。README を「見える本文は人間、畳んだ節は LLM」に
分けたのは、まだ分ける側の試行で、これからも続く試行錯誤のひとつ。
（確度: 「はず」「理想」「重要」のまま。畳んだ中身を LLM が読んだことは事実として断定し、各条件 1 回と書く）

LLM は人間用の文章を第一に読みにくる。著者はこの両立の難しさを、自分の README を自分で読んで冒頭 11 文で
